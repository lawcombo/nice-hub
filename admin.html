GitHub 연결

업로드 권한 확인

토큰은 저장하지 않습니다.

입력한 토큰은 GitHub API 요청에만 사용되며, 이 화면을 닫거나 새로고침하면 사라집니다.

lawcombo/nice-hub 저장소만 선택하고 Repository permissions의 Contents를 Read and write로 설정하세요.

토큰 만드는 방법 보기
  1. GitHub Fine-grained token 만들기 를 엽니다.
  2. Repository access에서 Only select repositories를 선택하고 `nice-hub`만 지정합니다.
  3. Repository permissions에서 Contents → Read and write만 설정합니다.
  4. 만료일을 짧게 지정해 생성한 뒤 토큰을 위 입력란에 붙여넣습니다.

등록 자료 관리

현재 업로드된 자료

GitHub 연결 후 자료 목록을 확인할 수 있습니다.

삭제하면 GitHub의 원본 파일과 표지도 함께 삭제됩니다.

업로드 전 확인

  • 업로드하면 `main` 브랜치에 자료 파일과 목록 정보가 한 번에 커밋됩니다.
  • GitHub Pages 반영에는 보통 잠시 시간이 걸립니다.
  • 공용 PC에서는 사용하지 말고, 작업이 끝나면 토큰을 폐기하거나 만료시키세요.
  • 큰 동영상은 저장소가 빠르게 커질 수 있으므로 외부 영상 URL 사용을 권장합니다.
